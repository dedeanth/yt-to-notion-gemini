Quick Setup Guide

1
Get Google Gemini API Key

Visit Google AI Studio, log in with Google, and click "Create API key". Paste it into the Gemini API Key field.

2
Create Notion Internal Integration

Go to notion.so/profile/integrations, click "New integration", name it (e.g. YouTube Saver), and copy the Internal Integration Secret.

3
Connect Notion Database

Open your target database in Notion, click the ... (top right) → Connections → Connect to → select your integration. Then copy the database link and paste it here.

4
Test & Save

Click "Test Connection & Fetch Schema" to auto-detect properties, then click "Save All Settings". You're ready to summarize and save!
